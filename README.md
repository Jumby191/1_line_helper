Скрипт search-log.sh печатает строки файла, в которых есть заданное слово.

Запуск: ./search-log.sh <файл> <слово>

Пример: ./search-log.sh sample.log ERROR

Коды выхода:

- 0 — строки найдены
- 1 — совпадений нет, вывод пустой
- 2 — файла нет, сообщение об ошибке остаётся на экране
